# 🛒 Java E-commerce Order Management

A simple **Java OOP project** that simulates an **E-commerce Order Management System** using **classes** and **enums**.

---

## 🧩 Features
- 🧍‍♂️ `Customer` class to store customer details (name, email)
- 📦 `Order` class to manage order ID, payment method, and status
- 🔢 `OrderStatus` enum to define order states (`PENDING`, `SHIPPED`, `DELIVERED`, `CANCELLED`)
- 💳 `PaymentMethod` enum to define payment types (`CASH`, `CREDIT_CARD`, `PAYPAL`)
- 🧠 Demonstrates Object-Oriented concepts: **encapsulation**, **composition**, and **enum usage**

---

## 🚀 How It Works
1. Two customers and two orders are created.
2. Orders start with a default status of **PENDING**.
3. The program updates the order status (e.g. `SHIPPED`, `CANCELLED`) and prints details before and after.
